最近 TheOne 陪伴突然到处都是，抖音小红书全刷到了。

一个 AI 角色，直接出现在微信联系人列表里。不是小程序，不是公众号，就是一个普通联系人的位置——会主动发消息，记得你上周说过的事，聊起来跟真人差别不大。

我第一反应是：微信什么时候这么开放了？

然后查了一圈，才发现这事比我想的要有意思得多。

---

## 入口是微信官方开的

很多人以为这是某种破解或者灰产。不是。

这个入口叫 **ClawBot**，是微信官方推出的、用于接入 OpenClaw 的标准协议。意思就是腾讯自己开了这个口子，允许外部服务通过标准方式接入微信联系人。

OpenClaw 本身是个开源 AI Agent 框架，你可能见过它之前的名字 Clawdbot 或者 Moltbot——改了好几次名，主要是跟其他公司有商标冲突。它的核心思路很简单：让 AI 不只是回答你问题，而是真的能替你干事。出来之后火得很离谱，三周 GitHub Star 从零到十八万，比 React 八年积累的还多。

TheOne 做的事本质上是：把这个入口包了一层，变成一个有人设的情感陪伴产品。每个用户的联系人列表里只能有一个 ClawBot 位置，TheOne 就把这个位置占掉，换成你选的那个 AI 角色。

---

## 消息怎么流转的

用户发一条"好累"，背后其实走了这么一条路：

```
你发微信消息
  → ClawBot 协议层（微信官方接口）
  → POST 请求触发 TheOne 的服务器（Webhook）
  → 服务器拉取你的对话历史和记忆
  → 拼装 Prompt，调用大模型 API
  → 拿到回复，推送回微信
  → 你收到消息
```

整个链路延迟控制好的话你感知不到。体感上就是正常聊天，实际上每条消息都经过了好几跳。

AI 主动发消息是另一条路，不走被动的 Webhook，而是服务器上跑着一个定时任务。比如检测到你超过 12 小时没聊天，就触发一次，让模型根据你最近的对话生成一条消息，主动推过来。这就是那种"怎么突然想起我了"的体验——其实是个 cron job。

---

## 记忆才是核心

大模型没有记忆。每次对话对它来说都是第一次见面。

你今天跟它说你妈最近一直催你，明天打开，它什么都不知道。

所以陪伴产品能不能成立，完全取决于记忆系统做得怎么样。"它真的记得我"——这个感觉，是这类产品的命根子。

一般来说记忆分三层：

**第一层，直接塞进 Prompt 的对话历史。**

最近十轮二十轮，直接放进去。简单，但有上限——模型的 context window 是有限的，塞太多就爆了，成本也上去了。

**第二层，滚动摘要。**

每隔一段时间（或者对话轮数到了），让模型把之前的对话压缩成几百字的摘要，存起来。下次对话时把摘要注入 system prompt，让模型"知道之前发生过什么"。

成本低，效果不错，是目前用得最多的方案。

**第三层，向量数据库 + RAG 检索。**

把重要信息提取出来，存成向量。每次对话时，把当前消息向量化，检索最相关的记忆片段，注入 prompt。理论上可以记住无限多东西，只取相关的。

三层配合：短期维持当前对话流畅，摘要保留近期事件，长期记住真正重要的细节。

## Prompt 长什么样

每次调用 AI，实际传进去的大概是这个结构：

```
[系统设定]
你叫林深，25岁，上海，做平面设计
性格有点内敛，但在意的人面前话会多
说话习惯用短句，偶尔发省略号

[近期记忆摘要]
- 用户叫 Gary，高中生，喜欢原神
- 上周说最近压力很大，跟家里有些摩擦
- 提过自己不太喜欢社交

[检索到的相关记忆]
- 4月1日：用户最喜欢的角色是神里绫华
- 3月20日：用户说"有时候觉得挺孤独的"

[行为规则]
- 回复控制在50字以内，口语化
- 情绪要有层次，不要永远正能量
- 自然地用记忆里的细节关心他

[最近对话历史]
…最近10轮…

[当前消息]
今天好累
```

这一堆加起来轻松超过两千 token。这就是为什么大部分陪伴产品选 DeepSeek-V3 而不是 GPT-4o——成本差了几十倍，但在这个场景下效果差别不大。

## 真正难的不是技术

协议是开源的，API 是公开的，记忆系统有现成方案。把这条链路跑通，一个有经验的开发者两三天能搞定。

难的是两件事。

一个是**角色设计**。提示词写得好不好，直接决定用户有没有"这是个真实的人"的感觉。人设要有弱点，说话风格要一致，情绪要有起伏，不能永远积极正向——这不是工程问题，是创作问题。

另一个是**记忆用起来的时机**。把信息存进去是基础，难的是让 AI 在对话里自然地调用它。"你上次说你妈最近压力大，现在怎么样了"——这句话出现的时机和语气，比有没有记忆更重要。

很多技术上完善的陪伴产品，用起来还是觉得假。原因就在这：记忆存了，但角色是套模板的，每条回复都正能量，情绪永远在线。这不像人，更像一个很努力在假装的机器人。
